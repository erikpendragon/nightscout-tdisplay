# Available firmware versions

The device follows `manifest.json` and always offers the newest build.
To pin it to a particular version - or to go back to an older one - set
**Update Manifest URL** on the device's web page to that version's
manifest. It will then stay there until you point it somewhere else.

| Version | Manifest URL to pin to | Full image |
|---|---|---|
| `9.9.9` | `https://erikpendragon.github.io/nightscout-tdisplay/v9.9.9/manifest.json` | [factory.bin](https://erikpendragon.github.io/nightscout-tdisplay/v9.9.9/cgm-display.factory.bin) |
| `1.0.1` | `https://erikpendragon.github.io/nightscout-tdisplay/v1.0.1/manifest.json` | [factory.bin](https://erikpendragon.github.io/nightscout-tdisplay/v1.0.1/cgm-display.factory.bin) |
